# How to reproduce my entry

## Summary

- **Entry:** release `entry-1` (pre-tournament): `submission/` = `agents/turn_transformer_rl`, weights
  SHA-256 `dbae26c11bf4e1eb2409a0d2dfab9d9541d94c090db807b5636c525a83ee1efb`. Tournament device: cpu.
- **Approach in two sentences:** a residual CNN reads each turn and a small causal transformer reads
  a summary of every earlier turn of the game (805,802 parameters, no search); it first imitates
  full-board Stockfish on games played by its predecessor, then learns from the results of its own
  Fog-of-War games (PPO with a value network) against the reference bots and its earlier versions.
- **One command:** `bash reproduce.sh` (about 6.5 hours on a 16-thread PC with one GPU). Each stage
  is skipped if its output exists, so the script can simply be rerun after a job time limit.

## 1. Environment

- Python 3.11 or newer, then `pip install -e ".[baseline]"` and `pip install psutil`
  (psutil lets the learning loop pause when memory is low; without it the loop still runs).
- Versions used for this entry: Python 3.12.10, torch 2.6.0 (CUDA 12.4), numpy 2.2.6,
  safetensors 0.8.0, python-chess 1.11.2, psutil 6.1.1. Windows 10, but the scripts are plain
  Python and bash.
- Stockfish 19: `bash scripts/get_stockfish.sh`, then `export STOCKFISH=…`. (The script downloads
  the latest release; this entry's labels came from Stockfish 19.)
- Optional: `DEVICE=cpu` or `DEVICE=cuda` (default: cuda if available).

## 2. Pipeline

Every command is in `reproduce.sh`, in this order. Times are from the original runs on one
personal PC (16 CPU threads, RTX 3060 Ti); Sol with 32 cores should be faster for the game stages.

| Stage | What | Output | Seed | Time and hardware |
|---|---|---|---|---|
| 1a | 75,000 games between reference bots, every position labelled by full-board Stockfish (5,000 nodes), encoded with `move_history`'s 29 input planes (`baselines/imitation/generate_data.py --record`) | `data/rec75k_s3`, `data/rec75k_s3_hist` | 3 | 50 min, 12 CPU workers |
| 1b | Train `agents/move_history` (`baselines/imitation/train.py`, 16 epochs, best held-out epoch kept) | `agents/move_history/weights` | 0 | 11 min, GPU |
| 2 | 54,000 branching games (0-10 random opening moves, later plies kept more often), mostly played by `move_history` against the bots and itself, labelled by Stockfish | `data/branch54k_s4`, `data/branch54k_s4_hist` | 4 | 78 min, 10 CPU workers |
| 3 | Train `agents/move_history_branch` on them (`--split view`) | `agents/move_history_branch/weights` | 0 | 12 min, GPU |
| 4 | Re-encode the same games as turn sequences and train `agents/turn_transformer` (`baselines/sequence/`) | `data/branch54k_s4_seq`, `agents/turn_transformer/weights` | 0 | 1 + 19 min, GPU |
| 5 | 60,000 games of `move_history_branch` against the three bots, to warm up the loop's value network (`baselines/fow_games/play_games.py`) | `data/fow_games` | 100 | 52 min, 12 CPU workers |
| 6 | Learning loop from `turn_transformer` (`baselines/fow_games/rl_loop.py`): 6,000 new games per round against the bots and its last 3 versions, PPO with a value network, a rating against the bots every 2 rounds (seed 9), stop after 3 ratings without a new best | `runs/rl_tf/best` | 7 | about 2.6 hours (14 rounds), CPU workers plus GPU |
| 7 | Copy `runs/rl_tf/best/weights/model.safetensors` into `submission/weights/`, then `fow.params`, `fow.validate` and the checksum | `submission/` | | 1 min |

- **Sources:** all data is generated by the code above with Stockfish and the reference bots;
  nothing is downloaded except Stockfish.
- **Assembling `submission/`:** its code (`agent.py`, `features.py`, `history.py`, `model.py`,
  `config.json`) is committed and identical to `agents/turn_transformer`; only the weights come
  from the pipeline.
- The script retrains the committed agents in stages 1b, 3 and 4 in place.

## 3. Expected results

- `python -m fow.validate submission --device cpu` prints VALID with 805,802 parameters and about
  5×10⁷ FLOPs per move.
- `turn_transformer` (stage 4): about 40% held-out match with the teacher; about 1450 against the
  three bots.
- Learning loop (stage 6): ratings on seed 9 rising for several rounds and then levelling off; the
  original run peaked at round 8 (1550 on seed 9) and stopped after round 14.
- The entry: about 1520 against the three bots
  (`python -m fow.arena submission bot:greedy bot:guess-sf-4x500 bot:guess-sf-16x1000 --games 200 --seed 6`),
  and about 62% head to head against `agents/turn_transformer`.

## 4. Compute used in total

About 4.5 CPU-hours of game play and labelling on 10-12 workers, and about 1.5 GPU-hours
(RTX 3060 Ti) for training and the rating games. All on a personal PC, not Sol.

## 5. Known sources of variation

- **Bots:** the Stockfish-based bots do not play the same moves on every run, so the games, and
  therefore the weights at every stage, differ from run to run.
- **Data:** different worker counts split the games differently.
- **Choosing the round:** the loop keeps the round with the best of several noisy ratings (±45
  Elo), so the round it picks can differ.
- **Not yet verified:** the whole pipeline has not been rerun from a fresh clone yet, so the size of
  the run-to-run difference is not measured. That check (a fresh run and 200+ games against this
  entry) is planned before the final entry.
